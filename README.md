# 余白の実験室

ホームページとブラウザゲーム6本の公開用ファイルです。

- ホームページの文章とゲームへのリンクは、トップ階層の `index.html` と `site-content.js` にあります。
- ホームページの見た目は、トップ階層の CSS ファイルで変更できます。
- ゲームは `games/` の中に作品ごとに入っています。
- 設定資料は `assets/documents/` にあります。

GitHub Pages は **Settings → Pages → Deploy from a branch → main → / (root)** で公開できます。公開後は、`main` のファイルを編集してコミットするとサイトに反映されます。

この版のゲームの進行は、そのブラウザ内に保存されます。移行前の公開URLで遊んだ記録は、移行先のURLでは新しい記録として始まります。
